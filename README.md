# Timer Pomodoro

## V2
- Поле **Циклов (0 = ∞)** — количество циклов «работа–перерыв»; 0 = бесконечно
- Счётчик циклов — отображает прогресс (например, «Цикл 3 из 8» или «Цикл 3» при 0)
- Таймер останавливается по завершении заданного числа циклов
- Кнопка **Сброс** обнуляет счётчик циклов

## V1
- Выбор длительности: работа (по умолчанию 25 мин) и перерыв (по умолчанию 5 мин)
- Кнопки: **Старт**, **Пауза**, **Сброс**
- Таймер с отображением оставшегося времени
- Статус: «Работа» / «Перерыв»

### Запуск
Откройте `index.html` в браузере.
